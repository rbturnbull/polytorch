DataFrames

Typed dataframe loading and indexing for PolyTorch features.

class polytorch.dataframe.PolyDataFrame(csv: Path | DataFrame, data_columns: set[str] | None = None)

Load columns annotated with PolyTorch data types.

Parameters:

  • csv – A pandas dataframe or a CSV filename supplied as a pathlib.Path.

  • data_columns – Annotated column names to include, without type suffixes. None or an empty collection includes all annotated columns.

pandas_df

The original dataframe, or the dataframe read from CSV.

data_types

Data type instances in source column order.

getters

Mapping from selected column names to indexable values.

Notes

Headers use name:type, such as score:continuous or group:CategoricalData. Whitespace around names and types is stripped. Unannotated columns remain accessible by their original names but are excluded from row tuples. Categorical and ordinal values are not encoded; supply integer category indices when using embeddings or cross-entropy.

Raises:

  • ValueError – A selected column has an unknown type, or a requested column is missing.

  • AssertionError – An annotated header contains multiple colons.

Examples

>>> import pandas as pd
>>> frame = PolyDataFrame(pd.DataFrame({"score:continuous": [0.25, 0.75]}))
>>> assert frame[0] == (0.25,)
>>> assert frame["score", 1] == 0.75
__getitem__(idx) → tuple

Return a row, column, or individual value.

Parameters:

idx – A Python or NumPy integer for a row tuple; a string for a column; or a (column_name, row_index) tuple for an individual value. Selected annotated columns use names without type suffixes. Original dataframe column names also provide access to raw values.

Returns:

A row tuple in selected column order, an indexable column, or a value. Hierarchical columns return node IDs through their parsed names and original path strings through their full annotated headers.

Raises:

  • KeyError – The key type or column name is unsupported.

  • IndexError – A row index is out of bounds.

  • AssertionError – A tuple key does not contain exactly two elements.

polytorch.metrics.calc_generalized_dice_score(predictions, target, power: float = 2.0, smooth: float = 1.0, feature_axis: int = -1) → Tensor

A generalized Dice score for multi-class segmentation.

If power=0.0, this is equivalent to normal Dice score (i.e. volume “implicit” weighting) If power=1.0, this is equivalent to ‘equal’ weighting. If power=2.0, this is equivalent to ‘inverse volume’ weighting.

See:

  • https://www.sciencedirect.com/science/article/pii/S2590005619300049#bib73

  • https://arxiv.org/pdf/1707.03237.pdf

  • https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=1717643

polytorch.metrics.generalized_dice(predictions, *targets, data_index=None, feature_axis=-1, perform_softmax: bool = True, power: float = 2.0) → Tensor

Calculate generalized Dice for one output in multi-class segmentation.

See:

  • https://www.sciencedirect.com/science/article/pii/S2590005619300049#bib73

  • https://arxiv.org/pdf/1707.03237.pdf

  • https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=1717643

Parameters:

  • predictions – A prediction tensor or sequence of per-output tensors. Values are logits, or probabilities when perform_softmax is False.

  • *targets – Integer class-index target tensors in matching output order.

  • data_index (int) – Required index of the output to evaluate.

  • feature_axis (int, optional) – Axis containing class scores. Defaults to -1.

  • perform_softmax (bool, optional) – Whether or not to normalize the predictions using the softmax function. Defaults to True.

  • power (float, optional) – The power to use for the generalized dice score. Defaults to 2.0 (i.e. inverse volume weighting) If power=0.0, this is equivalent to normal Dice score (i.e. volume “implicit” weighting) If power=1.0, this is equivalent to ‘equal’ weighting. If power=2.0, this is equivalent to ‘inverse volume’ weighting.

Returns:

The generalized dice score for the given data index.

Return type:

torch.Tensor
